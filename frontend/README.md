# Servus Dashboard (Frontend)

This `frontend/` app is a Vite + React UI that sits on top of the Servus backend.
It provides:

- A **live dashboard** mirroring the CLI view (agents, costs, tasks, and phases).
- A way to browse past sessions and their logs.
- A nicer landing page and marketing surface for the Servus project.

## Development

```bash
cd frontend
npm install
npm run dev
```

The app is a standard React + Vite project, so you can customize the UI,
branding, and pages like any other Vite app.
